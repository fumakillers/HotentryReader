# HotentryReader v0.1.0

HotentryReader の初回リリースです。

はてなブックマークのホッテントリを、Android 端末でさっと眺めるための閲覧専用アプリとして、基本的な閲覧体験を整えました。

## 主な内容

- ホッテントリ一覧表示
- はてなブックマークのコメント閲覧
- 左右スワイプによるカテゴリ切り替え
- プルリフレッシュ
- ミュートワード
- 正規表現ミュート

## インストール方法

Release Assets から `HotentryReader-v0.1.0.apk` をダウンロードし、Android 端末へインストールしてください。

Android の設定によっては、提供元不明のアプリのインストール許可が必要です。

## 注意事項

- 本アプリは個人開発の閲覧専用アプリです。
- はてなブックマークへのログイン機能やブックマーク追加機能はありません。
- APK は GitHub Releases の Assets として配布し、リポジトリには含めません。
